# Distinct Archives — Proposals

Static quotations and milestone websites for client review.

## Live site

Each client proposal is in its own folder. New Age: [`new-age/index.html`](new-age/index.html).

## Hosting with GitHub Pages

Open repository **Settings → Pages → Build and deployment**. Set **Source** to **Deploy from a branch**, select **main**, choose **/(root)**, and save.

Once GitHub finishes publishing, the New Age quotation will be reachable at `https://distinctarchives.github.io/Invoices/new-age/`.

**Privacy:** This is a public repository. The quoted prices and contents of these pages are public. A GitHub Pages link is not private or access-restricted.
